# Ulanzi TC001 Evolved — Release v2.2.0 ⏱️

## ⏱️ Continuous Real-Time NTP Synchronization & Automatic Daylight Saving Time (DST) Transitions

Release **v2.2.0** introduces continuous, zero-drift real-time clock synchronization powered by ESP-IDF's POSIX timezone engine. The clock now automatically and seamlessly applies daylight saving time transitions (such as the Central European transition between summer time CEST and winter time CET in Slovakia and Europe) in real time without requiring device reboots or manual adjustments.

---

### ✨ What's New in v2.2.0

#### 1. ⏱️ Continuous POSIX Real-Time Clock Synchronization
- **Solved One-Shot Boot Lock**: Resolved the condition where `checkNtpSync()` was previously bypassed once marked synced at boot, leaving the internal clock counter to run on local `millis()` ticks without re-evaluating system time.
- **Continuous Local Time Polling**: Queries `getLocalTime(&timeinfo, 0)` every second directly from the ESP32 hardware timer and internal POSIX timezone engine (`CET-1CEST,M3.5.0,M10.5.0/3`).
- **Immediate Daylight Saving Transitions**: Transitions seamlessly between standard time (CET, UTC+1) and daylight saving time (CEST, UTC+2) at 03:00 / 02:00 without delay or manual intervention.
- **Elimination of Crystal Drift**: Completely eliminates accumulated crystal oscillator frequency drift over long multi-week or multi-month uptime periods.

#### 2. ⚡ Zero-Overhead Non-Blocking Rendering
- **Instantaneous In-Memory Evaluation**: `getLocalTime(&timeinfo, 0)` executes in < 1 µs directly against internal RAM and CPU timers without triggering any blocking network requests or delays.
- **Hourly Background NTP**: Actual network NTP requests continue to be managed efficiently by ESP-IDF's background SNTP service once per hour (3,600s), avoiding network congestion while keeping precision exact.
- **Render Timeout Elimination**: Reduced `getLocalTime` timeout in `renderClockApp()` from 10 ms to 0 ms, completely eliminating any display frame-pacing stalls when operating offline or during network dropouts.

#### 3. 📱 Companion App Ecosystem Foundation
- Created the dedicated open-source repository for the upcoming native Android Companion App: [hackra76/Ulanzi-TC001-Companion](https://github.com/hackra76/Ulanzi-TC001-Companion).

### 📦 Installation & Upgrade

#### Over-The-Air (OTA) Update (Recommended)
1. Open the clock's Web Configuration Portal (`http://<device-ip>/`).
2. Go to **Panel 05: FIRMWARE OTA**.
3. Click **Check GitHub Releases** and tap **Install v2.2.0 Now**, or upload `firmware.bin` directly.

#### USB Flashing (First-Time / Clean Install)
```powershell
$env:PYTHONIOENCODING="utf8"; pio run -t upload
```
*Or flash `firmware.factory.bin` directly via ESP Web Tools or esptool at offset 0x0000.*
