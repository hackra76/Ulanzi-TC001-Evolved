# Ulanzi TC001 Evolved — Release v2.1.0 📅

## 📅 High-Legibility 9×8 Dynamic Calendar Icon & Display Layout Optimization

Release **v2.1.0** introduces a dedicated visual redesign for the dynamic calendar icon, upgrading its footprint to **9×8 pixels** to provide a permanent **1-pixel separation gap** between tens and units digits. This completely solves the character collision and solid-stripe blur previously experienced on double-digit dates (e.g. 22, 23, 30, 31).

---

### ✨ What's New in v2.1.0

#### 1. 📅 9×8 Dynamic Calendar Icon
- **Upgraded Dimensions**: Expanded icon width from 8×8 to 9×8 (9 columns wide, 8 rows high).
- **Dedicated 1px Separation Gap**: Column 4 serves as an unpainted white separator column between the tens and units digits, guaranteeing digits never touch or merge into horizontal bars on dates 10–31.
- **Symmetrical Bilateral Borders**: Left border (col 0) and right border (col 8) maintain clean 1-pixel white margins.
- **Centered Single-Digit Dates**: Days 1–9 are centered at columns 3–5 with balanced 3-pixel margins on both sides.
- **Authentic Dual Rings**: Dual mounting rings at columns 2 and 6 align over the tens and units digits.

#### 2. 📐 Display Screen Alignment & Budget Optimization
- **Date Screen**: Recalibrated text `startX` for all date formats (`DD.MM.`, `DD MMM`, `MM/DD`, `DAY DD`) across the remaining 23 columns.
- **Time & Weekday Bar Spacing**: Standard time (`HH:MM`) and the 7-segment weekday bar start at column 10/11 with 1–2 pixels of clear margin from the 9px icon.

#### 3. 🎬 YouTube Showcase & Video Links
- Integrated official YouTube Shorts video links and badge embeds across all README files (`README.md`, `README_EN.md`, `README_SK.md`) and wiki documentation.

### 📦 Installation & Upgrade

#### Over-The-Air (OTA) Update (Recommended)
1. Open the clock's Web Configuration Portal (`http://<device-ip>/`).
2. Go to **Panel 05: FIRMWARE OTA**.
3. Click **Check GitHub Releases** and tap **Install v2.1.0 Now**, or upload `firmware.bin` directly.

#### USB Flashing (First-Time / Clean Install)
```powershell
$env:PYTHONIOENCODING="utf8"; pio run -t upload
```
*Or flash `firmware.factory.bin` directly via ESP Web Tools or esptool at offset 0x0000.*
