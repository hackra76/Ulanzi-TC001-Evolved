# Ulanzi TC001 Evolved — Release v2.6.0 ⚡🎵

## ⚡ Asynchronous Dual-Core Architecture, Melodic Sound Engine & Comprehensive Control APIs

Release **v2.6.0** delivers a major architectural upgrade to the Ulanzi TC001 Evolved firmware, introducing dual-core asynchronous background networking, a non-blocking melodic sound sequencer with RTTTL ringtone playback, unified REST and MQTT audio control APIs, diagnostic telemetry for Home Assistant, adaptive sensor filtering, and an interactive Web Portal buzzer testbench.

---

### ✨ What's New in v2.6.0

#### 1. ⚡ Asynchronous Dual-Core Background Worker (Core 0 Offloading)
- **Zero-Latency Rendering**: Pinned a dedicated FreeRTOS worker task to ESP32 **Core 0 (PRO_CPU)** to execute all blocking HTTP/TLS network requests for Weather, Crypto, YouTube, and Live Airspace.
- **Dedicated 60+ FPS Display Engine**: Completely frees **Core 1 (APP_CPU)** for uninterrupted 8×32 matrix rendering, smooth screen transitions, and instant physical button debouncing without stutter or UI freezes during network handshakes.
- **Decoupled Airspace Telemetry**: Separated live radar UI updates from API polling, allowing smooth flight callsign carousel rotation even during slow network responses.

#### 2. 🎵 Non-Blocking Melodic Tone Sequencer & RTTTL Ringtone Player
- **Asynchronous Audio Queue**: Replaced blocking delay loops with a non-blocking tone queue serviced continuously by `Buzzer_Poll()`.
- **5 Built-in Audio Presets**:
  - `Click` (1): Tactile UI confirmation click.
  - `Alert` (2): Double-pulse attention tone.
  - `Success` (3): Ascending major triad melodic chime.
  - `Notification` (4): Melodic 4-note notification chime.
  - `Alarm` (5): Alternating dual-frequency alarm siren.
- **Full RTTTL Parser**: Integrated standard Ring Tone Text Transfer Language (`Buzzer_PlayRTTTL`) engine allowing the clock to play custom retro 8-bit melodies and chimes.
- **Instant Dismissal**: Synchronized `Buzzer_Stop()` with countdown timer dismissal and remote stop triggers.

#### 3. 🌐 Comprehensive Audio REST & MQTT Control APIs
- **REST Endpoints (`/api/buzzer` & `/api/sound`)**:
  - `POST /api/buzzer`: Trigger audio presets (`sound="success"`), custom tones (`freq=2400&duration=100`), or RTTTL strings (`rtttl="..."`).
  - `GET /api/buzzer`: Query active playback status (`{"status":"ok","playing":true}`) without triggering audible tones.
  - Immediate playback cancellation via `POST /api/buzzer?stop=1` or `{"action":"stop"}`.
- **MQTT Audio Control**:
  - Subscribes to `<prefix>/buzzer/set` and `<prefix>/sound/set` supporting presets 1–5, text identifiers (`"click"`, `"alert"`, `"success"`, `"notification"`, `"alarm"`, `"stop"`), raw RTTTL strings, and JSON objects.
- **Carousel Rotation Preservation**: High-priority push notifications now reset `s_lastAppSwitch`, ensuring the interrupted application retains its full configured rotation duration after notification dismissal.

#### 4. 🎛️ Interactive Web Portal Buzzer Testbench & Status Diode
- **Acoustic Signal Testbench**: Tactile control panel in the Web Configuration Portal featuring instant-trigger buttons for all 5 presets, stop button, and a live RTTTL melody test field.
- **Header Status Diode**: Added real-time **AUDIO** status indicator diode in the top instrument header cluster, illuminating bright orange during active tone/melody playback.
- **Full Localization**: Integrated English and Slovak (`[EN | SK]`) translations for the new audio controls.

#### 5. 🏠 Extended Home Assistant MQTT Auto-Discovery (15 Entities)
- Extended auto-discovery suite to 15 entities with dedicated diagnostic sensors:
  - **Wi-Fi Signal RSSI** (`sensor/wifi_rssi`): Real-time link signal strength in dBm.
  - **Free Memory** (`sensor/free_heap`): Monitored internal heap memory in bytes.
- Tagged with `entity_category: "diagnostic"` for clean organization within Home Assistant device dashboards.

#### 6. 🔋 Sensor Stabilization & Flash Memory Protection
- **8x Battery ADC Oversampling & EMA Filter**: Implemented 8-sample hardware averaging and exponential moving average (EMA) filtering on `PIN_BATTERY_ADC` to eliminate Wi-Fi RF burst voltage droops and percentage jitter.
- **Adaptive LDR Deadband Hysteresis**: 0.8-unit deadband hysteresis eliminates auto-brightness micro-flicker around ambient light thresholds.
- **Cinematic Slew-Rate Limiter**: Smooth 1-step / 40ms brightness ramp delivers clean, cinematic auto-brightness transitions.
- **Debounced NVS Commits**: 500ms debouncing window on brightness slider commits prevents SPI flash memory wear during rapid slider movements.

### 📦 Installation & Upgrade

#### Over-The-Air (OTA) Update (Recommended)
1. Open the clock's Web Configuration Portal (`http://<device-ip>/`).
2. Go to **Panel 05: FIRMWARE OTA**.
3. Click **Check GitHub Releases** and tap **Install v2.6.0 Now**, or upload `firmware.bin` directly.

#### USB Flashing (First-Time / Clean Install)
```powershell
$env:PYTHONIOENCODING="utf8"; pio run -t upload
```
*Or flash `firmware.factory.bin` directly via ESP Web Tools or esptool at offset 0x0000.*
