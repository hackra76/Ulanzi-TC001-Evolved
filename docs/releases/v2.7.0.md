# Ulanzi TC001 Evolved — Release v2.7.0 💾🔄

## 💾 Native Configuration Backup & Restore Engine with Web Portal & REST APIs

Release **v2.7.0** introduces a complete, robust Configuration Backup and Restore subsystem to the Ulanzi TC001 Evolved firmware. Users can now export their entire clock setup (Wi-Fi profiles, clock & date styling, 7-day weekday indicators, ambient photometry, 9-screen carousel parameters, meteorological and financial tickers, screensavers, and MQTT broker settings) to a standardized JSON backup file, or restore their configuration on demand via the Tactile Web Portal or direct REST endpoints.

---

### ✨ What's New in v2.7.0

#### 1. 📤 Complete Configuration Export Endpoint (`GET /api/backup`)
- Streams a complete, validated snapshot of all device settings stored in NVS (`ulanzi_cfg` namespace).
- Automatically sets `Content-Disposition: attachment; filename="ulanzi_tc001_backup.json"` for instantaneous one-click browser downloading.
- Standardized, human-readable JSON structure detailing:
  - **Wi-Fi Multi-Profile Memory**: Profiles 1 through 4 (SSIDs and keys).
  - **Clock & Calendar Architecture**: Display modes, date format, icon style, alignment, seconds toggle, and 7-day weekday color scheme (active, inactive, weekend).
  - **Screen Navigation & Carousel**: Auto-rotation state, cycle interval, transition FX, active screen, rotation bitmask, and screen sequence ordering.
  - **Ambient Photometry**: LDR auto-brightness toggle, day ceiling, night floor, quiet red night mode and schedule hours.
  - **Screensaver Engine**: Visual style (Matrix Rain, Fire, Pac-Man, Game of Life, Dynamic Shuffle) and inactivity timeout.
  - **Data Feeds & Integrations**: Outdoor weather coordinates, city name, crypto/market ticker symbol, YouTube channel & credentials, and Home Assistant MQTT broker configuration.

#### 2. 📥 Full Configuration Restore Endpoint (`POST /api/restore`)
- Accepts standard JSON payload exported by either the Web Portal or the official Android Companion App.
- Automatically handles wrapped (`settings: { ... }`) or flat JSON structures with granular type validation.
- Atomically updates all persistent parameters to NVS flash memory.
- Immediately invokes live runtime setters (`Weather_SetConfig`, `Crypto_SetSymbol`, `YouTube_SetCredentials`, `Screensaver_Set...`, `Network_Set...`), avoiding mandatory device reboots.
- Triggers an acoustic confirmation click tone (`Buzzer_Click()`) upon successful application.

#### 3. 🎛️ Tactile Web Portal Backup & Restore Deck (Panel 04)
- **Direct Download Action**: Integrated `⤓ Download Backup (.json)` button triggering instant browser file download.
- **Client-Side File Importer**: Non-blocking HTML5 `FileReader` uploading selected JSON configuration files directly via AJAX to `/api/restore`.
- **Live Status Feedback**: Phosphor green / signal red visual indicator with automatic 1.5s portal reload upon successful restore.
- **Dual Localization**: Full English and Slovak (`[EN | SK]`) i18n support for all backup/restore dialogs, buttons, and confirmation alerts.

### 📦 Installation & Upgrade

#### Over-The-Air (OTA) Update (Recommended)
1. Open the clock's Web Configuration Portal (`http://<device-ip>/`).
2. Go to **Panel 05: FIRMWARE OTA**.
3. Click **Check GitHub Releases** and tap **Install v2.7.0 Now**, or upload `firmware.bin` directly.

#### Factory Flash (USB Serial)
- Connect via USB-C and run:
  ```bash
  esptool.py --chip esp32 --port <PORT> --baud 921600 write_flash -z 0x0 firmware.factory.bin
  ```
