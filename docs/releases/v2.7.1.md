# Ulanzi TC001 Evolved — Release v2.7.1 ⏱️✨

## 🛡️ Seamless Screensaver Lifecycle, Carousel Synchronization & Web Portal Controls

Release **v2.7.1** resolves critical screensaver deactivation and carousel progression issues in the Ulanzi TC001 Evolved firmware. The screensaver subsystem now fully respects auto-rotation carousel timings, immediate remote deactivation commands, inactivity timeout disabling, and hardware button wake triggers, with brand new manual testing controls integrated directly into the Tactile Web Portal.

---

### ✨ What's New in v2.7.1

#### 1. 🔄 Non-Blocking Screensaver Lifecycle & Carousel Progression
- **Automated Carousel Transition**: If auto-rotate carousel is enabled (`Network_GetAutoRotate() == true`), the screensaver renders for the configured rotation interval before seamlessly deactivating and cycling forward to the next scheduled screen in the carousel sequence, eliminating infinite freeze states.
- **Instant Inactivity Timeout Disabling**: Setting inactivity timeout to `0` (Disabled / Carousel Only) immediately wakes and deactivates any running screensaver, reverting to Clock (`APP_CLOCK`).
- **Remote App Switching Wake**: Selecting or navigating to any application screen (Screen 0–7) via Web Portal or Companion App instantly terminates the screensaver.
- **Hardware Button Wake & Audio Feedback**: Pressing any physical button (Left, OK, Right) while a screensaver is playing now immediately deactivates the screensaver, emits an acoustic tactile click tone (`Buzzer_Click()`), and returns to Clock.
- **Activity Reset on Critical Actions**: All incoming custom app pushes (`/api/custom`), notification triggers (`/api/notify`), and backup restores (`/api/restore`) reset inactivity timers and immediately wake the clock.

#### 2. 🎛️ Manual Screensaver Controls in Web Portal (Panel 02)
- Added direct interactive controls under Carousel & Screen Management:
  - **▶ Start Screensaver**: Immediately triggers selected visual effect for testing or ambient display.
  - **■ Exit / Wake Clock**: Immediately terminates screensaver playback and awakens the clock to primary mode.
- Integrated visual status feedback with automatic 3s auto-dismiss.
- Full localization in English and Slovak (`[EN | SK]`).

### 📦 Installation & Upgrade

#### Over-The-Air (OTA) Update (Recommended)
1. Open the clock's Web Configuration Portal (`http://<device-ip>/`).
2. Go to **Panel 05: FIRMWARE OTA**.
3. Click **Check GitHub Releases** and tap **Install v2.7.1 Now**, or upload `firmware.bin` directly.

#### Factory Flash (USB Serial)
- Connect via USB-C and run:
  ```bash
  esptool.py --chip esp32 --port <PORT> --baud 921600 write_flash -z 0x0 firmware.factory.bin
  ```
